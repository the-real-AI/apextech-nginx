Документация и Руководство Nginx

Технические спецификации, параметры маршрутизации и справочник команд локального веб-сервера.

Разделы Документации
  • Введение
  • Файл nginx.conf
  • Маршрутизация
  • Команды CLI

1. Введение

Веб-платформа ApexTech работает на высокопроизводительном сервере Nginx v1.26. Сервер обрабатывает входящие сокет-соединения на порту 80 с привязкой доменного имени akram.local (192.168.60.38).

2. Конфигурация Nginx

Основные параметры сервера прописаны в файле C:\nginx\conf\nginx.conf:

server {
    listen 80;
    server_name 192.168.60.38 akram.local;

    location / {
        root html;
        index index.html index.htm;
    }

    error_page 404 /404.html;
    location = /404.html {
        root html;
    }
}

3. Команды управления CLI

# Перезагрузить конфигурацию сервера без остановки
cd C:\nginx; .\nginx.exe -s reload

# Проверить синтаксис конфига на ошибки
cd C:\nginx; .\nginx.exe -t
